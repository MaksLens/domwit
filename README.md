# DomWit — Безопасная аренда без посредников

Платформа прямой аренды недвижимости: арендатор ↔ собственник без агентов. Верификация через Госуслуги/ЕГРН, Trust Score, Fair Price (ИИ-оценка), Instant Apply, Quality Score.

## Стек

- **React 18** + Vite
- **React Router v6** — навигация
- **Lucide React** — иконки
- **Recharts** — графики в дашбордах
- Inline styles (без Tailwind / MUI)
- Шрифт: Manrope (Google Fonts, кириллица)

## Запуск

```bash
npm install
npm run dev       # dev-сервер на http://localhost:5173
npm run build     # production-сборка
npm run preview   # превью production-сборки
```

## Sprint 5 — Чат и коммуникация

### `domwit-chat.jsx`
- Двухпанельный desktop-лейаут (340px сайдбар + панель переписки)
- Мобильный: полноэкранный список → переход в чат
- 6 диалогов с мок-данными, Trust Score, онлайн-индикаторы
- Пузыри сообщений (свои — справа/синие, чужие — слева/серые)
- Галочки прочтения (✓✓), временны́е разделители
- **Inline action cards**: «Запросить просмотр», «Предложить условия», «К договору»
- **Антифрод**: авто-детект номеров телефонов, ссылок на мессенджеры, слов «предоплата/аванс/задаток» → жёлтый баннер-предупреждение
- **ИИ-подсказки** для собственника над полем ввода (контекстные, закрываемые)
- Симуляция typing indicator (3 точки)
- FAB «Прокрутить вниз» при скролле вверх

### `domwit-notifications.jsx`
- 10 уведомлений в 3 группах: «Сегодня», «Вчера», «Ранее»
- 6 типов: сообщение, отклик, статус сделки, оплата, истекает объявление, верификация
- Клик → пометить прочитанным; кнопка «Прочитать все»
- Таб «Настройки»: матрица Toggle (5 категорий × 3 канала: Push / Email / In-app)
- Режим уведомлений: «Все» / «Только важные» / «Не беспокоить»
